# Log ...🚀

Follow this format for your log entries:

Date: March 12th
Update: I began creating my rough draft of layout on paper. This includes 6 pages including Login, User Profile, Trade, Explore, Locator, and Events. I started by establishing a nav bar, location of some icons, and placeholders for design elements like images.

Date: March 14th
Update: This update is building upon work created on the 12th. I added heading and established some specifics on design elements. For example, I decided that I would the books to be displayed on a digital book shelve to bring some texture and visual appeal.

Date: March 15th
Update: This update included adding 2 more pages that I overlooked including Book Details and Settings Page. Book Detail page can only be accessed from clicking on book in either trade, explore, or user profile. Made final touches on paper rough draft

Date: March 16th
Update: For this update, I created my Collect & Swap logo design. I used Canva to create it using some provided design elements. I knew I wanted to logo to feature a book or stack of books. In all I created 3 logos, something simple and to the point, one more detailed, and the final product which was a mix of the two. It features hands passing a book with the app name, I felt like this was very fitting since my app concept revolves around book sharing.

Date: March 17th
Update: This update is for the beginning of Figma wireframe creation. So far I have created all 8 pages and have began adding design elements that each page shares such as the navigation bar, icons, logo, and app name.

Date: March 20th & 21st
Update: Made adjustments to Figma wireframe to address comments left. These changes included narrowing down settings menu options, changing color of back arrows for better visibility, and added highlights on current page in navigation bar, settings icon and user profile icon.

Date: March 22nd
Update: My focus was to work on the desired workflow of the app. I used Figma's prototype functionalities to establish working navigation within the application. This includes working nav bar, buttons, settings icon, user profile icon, and back buttons.

Date: March 23rd
Update: My goal was to make finishing touches to my prototype. I discovered some additional support pages that I needed to add including book club details page, new book club form page, trade request form page, and new event form page. I added some buttons to support my new pages and updated how the navigation should work with the new elements. I also went back and decided on categories to display on trade and explore pages.

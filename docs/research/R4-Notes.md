## Sub-Topic 1 - Strengthening my Prototype

The focus of this research is on ways I can refine my prototype. By utilizing user feedback and proofing for visual consistency and completeness, I can ensure my final product is up to standard.

- User Feedback insight: User testing sessions are crucial for revealing pain points or usability issues that may not appear to developers. Gathering feedback from potential users will help identify areas for improvement in the user interface and overall experience.

- Visual Consistency: Ensuring a consistent visual design through the prototype, including typography, button styles, and color pallet, enhances user familiarity and confidence while navigating an app. This includes aligning all components with the established color palette and logo.

- Functional Completeness: It is essential to verify that all intended features are fully functional and integrated, such as routing, state management, and component interactions. This completeness guarantees that users can navigate the app as expected without encountering dead ends or issues.

## Sub-Topic 2 - Planning for future development

This topic revolves around the next steps when planning for future development. Including best practices for maintaining and establishing a clear roadmap that will lead to success.

- User-Centric Development: Prioritizing features based on user feedback collected post-launch can lead to improved user satisfaction and retention. Surveys or interviews can be effective in understanding what consumers enjoyed, any pain points, what can be improved or any desired features.

- Roadmap Creation: Developing a clear roadmap for future features, enhancements, and maintenance tasks will help to keep the project organized and ensure all team members understand the plan moving forward. This roadmap should be adjusted to reflect ongoing user feedback.

- Testing and Quality Assurance: Establishing a regular testing and maintenance schedule is vital for identifying and fixing bugs. This can include unit tests, integration tests, and performance monitoring to ensure the app remains reliable and performs well over time.

<br>

## Sub-Topic 3 - Deployment with Heroku

This topic research reflects the critical steps for setup and configuration when using Heroku to ensure a successful launch.

- Environment Configuration: Properly configuring environment variables and production settings are crucial for ensuring the app runs as intended on Heroku. This involves using a .env file for local development and configuring these settings through Heroku's dashboard for production.

- Database Management: Setting up your database involves creating the database, running migrations, and seeding initial data. Understanding the differences between local development databases and production databases is key for successful deployment.

- CI/CD integrations: Implementing Continuous integration (CI) and continuous deployment (CD) workflows can streamline the deployment process. By integrating Github with Heroku, you can automate the deployment of any code changes pushed to your repo, ensuring a smoother and faster deployment.

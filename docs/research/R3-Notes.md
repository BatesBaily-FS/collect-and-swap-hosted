## Sub-Topic 1 - User-centered design principles

This topic dives into the importance of designing with the end-user in mind. Exploring strategies for gathering user feedback, conducting usability testing, and iterating on design based on real user experiences to create a more user-friendly application.

- Dialog should reflect the user's language and present clear options. User feedback should include questions and prompts that are relevant to users and easy to understand. When gather feedback, it is crucial to ensure the correct language is used in surveys or interviews to align with the specific customer. Clear language leads to a better understanding and helps uncover real insight about experience and issues, making it easier for designers to address these problems.

- Conducting usability testing is crucial for observing how users interact with dialog. By observing users during usability tests, designers can identify when dialog interrupts the workflow and whether it is viewed as helpful or annoying. This direct observation helps understand user behaviors, allowing designers to refine dialog interactions and ensure they support user tasks without causing frustration.

- After usability testing and gathering feedback, designers should prioritize making dialog clean and user-friendly by simplifying dialog and avoiding unnecessary complexity. Iteratively refining dialog design based on user testing results ensures that they are intuitive and align with user expectations. Regularly revisiting and adjusting dialog designs allows for gradual improvements that enhances the overall user-experience.

## Sub-Topic 2 - Common design mistakes to avoid

This topic identifies pitfalls to steer clear of during design and development process. Understanding these common mistakes can lead to more effective user experience and ensure the application meets goals.

- Confirmshaming is a marketing tactic that uses specific wording to discourage users from doing something specific like not signing up for a newsletter. The approach with this tactic is daring and bold, and can come across to users as shaming hence the name confirmshaming. An example of this is a the exit button of the for the newsletter saying "No thanks, I am not a fan of the outdoors" on a outdoor business page. This marketing tactic comes with more risks than benefits, as it can offend the customer and overall gives a sense of poor lack of judgement.

- At first glance of a website, there are a few tells of a poorly put together design. Theses tells include overcrowding, no distinct focal point, misalignment, chaotic color-schemes, clarity issues, poor choice of data visualization, and bad resolution. Each one if these common mistakes is easy to avoid with careful attention to detail and user feedback is also helpful.
  Examples of these are:
  Color-scheme with conflicting colors or too many different colors
  Design elements blending into background and effecting element visibility
  Picture, graphs, header, and text being noticeably misaligned
  Too many elements in one space causing visual chaos
  Poor image resolution making icon or picture hard to see

- Some more notable mistakes to avoid when designing are poor navigation, content overload, website lagging, disruptive pop-ups, and ignoring accessability. Examples of these are:
  Hidden or confusing navigation menus
  Long blocks of text, too many images, or unnecessary elements
  Low speeds due to images that are too large or poor server performance
  Excessive or poorly timed pop-ups
  Lack of alt text for images and poor color contrast

## Sub-Topic 3 - Core design principles for production

This topic covers essential design principles like hierarchy, balance, and contrast. By applying these concepts during production process, you can create a cohesive ans visually appealing application that meets users needs ans enhances their experience.

- Implementing a clear visual hierarchy is essential for guiding users through an application. By prioritizing elements based on their importance - such as using larger fonts for headings and strategic placement of key features. This clarity not only enhances user experience but also streamlines the production process by reducing the need for revisions and adjustments later on.

- Balance in design refers to the distribution of visual weight within an application. By achieving either symmetrical or asymmetrical balance, designers can create a sense of harmony. A well-balanced design minimizes user confusion and enhances usability. A balanced layout can create a smoother production process by ensuring that all elements are cohesively integrated, reducing the likelihood for design flaws that may arise from uneven distribution of visual elements.

- Contrast is a powerful tool in design that helps highlight important elements and improve readability. By using contrasting colors, sizes, and shapes, designers can draw attention to key features and calls to action, making an application more engaging. In production, effectively applying contrast can lead to a more visually appealing product that meets users needs. Not only enhancing user experience but also supports a strong production plan by ensuring that the final product is both functional and aesthetically pleasing.

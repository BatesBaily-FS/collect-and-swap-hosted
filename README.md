# 📚 Collect and Swap

Collect and Swap is a web-based application designed to help users trade and share physical books, discover new titles, and connect with fellow book enthusiasts through virtual book clubs and local literary events.

The platform encourages affordable book ownership, promotes sustainability through repurposing of books, and fosters a sense of community for readers by combining trading features with social functionality.

---

## 🌟 Features

- ✨ Create a personal, shareable book collection using the Google Books API
- 🔁 Propose and accept book trades between users using a token-based system
- 📚 Join or create virtual book clubs based on favorite titles or genres
- 📆 Post and browse book-related local events
- 🔐 Login / Sign up functionality (Auth0-ready integration)
